# Enhanced Visuals

Better graphics and extra visual effects for HELLDIVERS (2015), for the [Obsidian](https://github.com/Alomare/ObsidianLauncher) mod manager.

The mod turns on the ambient occlusion pass that the game ships but never runs, adds sharpening and an ambient light effect, raises the resolution and distance of sun shadows, softens shadow edges, keeps detailed models farther from the camera, and can draw the scene above the screen resolution.

## How to use

**F9** switches between Enhanced Visuals and the plain game, to compare. The key can be changed in Obsidian.

For the game textures at twice the size, see [Upscaled Textures](https://github.com/Alomare/HD1-UpscaledTextures), a separate mod that works with or without this one.

## Known issues

- Third Person Camera also uses F9: with both mods on, change one of the keys. Put Enhanced Visuals after Third Person Camera in the load order, or the shadow and render scale options do nothing.
- A shadow resolution of 8192 takes 256 MB of video memory.
